# 租户预付费账户以估算预留和独立售价结算

用户于2026-11-17选择首版以租户为计费账户，统一人民币CNY，采用预付费并允许有限透支。余额加透支额度减在途预留足以覆盖本次估算费用时原子准入；项目可设子限额，新增项目或Key不增加租户额度。实际结算高于估算可能使欠款超出透支额度，因此不宣称最终欠款硬上限。

客户售价独立于上游成本，每次调用固定准入时的售价版本；缺少适用售价或计费规则拒绝调用，免费须显式配置零售价。已提交但结果未知时保留预留，跨重启待对账，核实后结算或释放并记录原因和审计。上游成本未知不记为零，异币种成本未经明确换算不直接参与利润计算。

路由回退时仍按客户请求的对外模型售价版本计费，平台承担实际供应商或模型变化带来的上游成本差异；该规则不改变能力降级须显式授权的协议边界。具体计费用量规则另行明确。

流式调用部分输出后取消或断流，按已核实的上游实际用量向客户计费，可能包含上游已生成但客户未收到的内容；用量未知仍保留预留待对账，不因请求失败直接记为零消费。账单需标记取消或中断状态。

同一次客户调用发生重试或回退时，仅按最终服务该调用的一次尝试用量向客户计费，此前失败尝试的上游成本由平台承担并逐次记录。未知尝试成本仍须待对账，不视为零成本；该计费选择不放宽安全重试边界。

网关精确缓存或语义缓存命中时客户调用费为零，显式记录命中状态；向量生成等辅助上游成本由平台承担并独立归集，不因客户免费而记为零成本。该规则不等同于模型供应商的缓存输入优惠价，后者仍按正常调用的冻结价目与usage规则处理。

人民币入账单位为0.000001元（小数点后6位），不足该单位的费用尾数按租户持久累计，不逐次丢弃或按流式片段取整。准入估算预留向上取整；最终结算合并全部计价项与该租户已保留尾数后，入账完整单位并保留剩余尾数。并发结算、充值冲正、归档和恢复均须保持已入账金额及尾数一致，明确免费调用不消费或触发历史尾数入账。

文件上传、查询、删除及任务查询等管理操作显式零价，上游成本由平台承担；任务创建若启动实际模型执行，不属于免费查询。批量模型执行、语音转写及附加付费工具使用独立计费规则，缺适用规则则拒绝。异步执行关联原计费对象，管理轮询不重复收费；附加工具维度与所属模型费用按规则组合，不能漏收或重复收取。

支持客户显式幂等键，在约定有效期内同项目、相同键和请求防止重复执行，相同键但请求内容不同则拒绝；结果未知保留状态，不自动重新提交上游。不带幂等键的相同正文仍视为新调用，X-Request-Id不是幂等键。不承诺端到端exactly-once。

流式重复提交只返回原调用标识与状态，不重新播放SSE，不再次执行或收费；在途流仅交给原连接。该能力提供防重而非断线续传或原始响应重放，正文记录不作为重放存储。

客户幂等键默认在调用确定结束后保留24小时，期限可配置；仍在执行或结果未知、待对账的调用不因TTL失去防重保护。有限期限过期的键可再次作为新调用执行和收费。TTL控制客户请求防重窗口，不缩短金额结算幂等记录、账务或未决任务的保留规则。

项目金额子限额采用累计额度，已消费加在途预留参与准入；调整限额不清空历史消费与预留，不增加租户余额或透支额度。实际费用超过估算可使项目累计消费超出子限额，随后按新状态阻止新调用；该子限额不是最终费用硬上限。

预留按显式模型规则估算：输入由对应计量器估算，输出按请求上限，未指定上限时使用显式配置的模型默认估算值；图片、视频等按数量、规格、时长估算。缺适用规则拒绝调用，不隐式改写客户参数，不将估算用量当权威实际用量；估算仅用于准入预留，最终仍按已确认的实际用量规则结算。

首版由平台代管外部客户，仅发调用Key，不提供客户门户或自助注册。管理员核实收款后追加充值流水，凭证防重，纠错追加冲正，不直接修改余额。充值、消费、冲正和对账流水长期保留并支持可核验归档，归档不得改变余额、累计消费或待对账预留。在线明细窗口、归档介质与恢复流程尚待设计；本决定不批准在线支付或集群存储实现。

该取舍接受估算误差与人工运营成本，换取明确的客户报价和可追溯资金变动。财务账本与现有累计token配额是不同合同，不能直接以token统计替代金额流水。
