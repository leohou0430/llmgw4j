# 首期控制面采用内置登录与分级RBAC

用户在2026-11-12选择首期内置账号登录与分级RBAC，而非把企业OIDC/SSO作为首期接入前提；区分平台管理员、租户管理员、项目管理员和项目只读观察者。人类控制面账号与模型调用API key是不同身份，授权必须受租户/项目范围约束，不能把现有HS256调用JWT视作已完成管理登录。

账号持久化、角色作用域和已发登录会话会形成长期身份合同，后续引入其他身份源需要显式映射。密码/会话安全、管理员初始化、具体动作表、审计和旧管理接口兼容方式仍待整体设计审阅，不表示已批准某项安全库或已实现企业身份平台。
