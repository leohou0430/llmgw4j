# 单Java进程与嵌入SQLite承载首期产品

用户明确数据面、控制面与持久存储运行预算合计2C2G，并在2026-11-12选择单Java进程＋嵌入SQLite，而非Java应用加独立数据库服务。首期元数据持久化使用SQLite，控制面与数据面同进程；管理网页若纳入，由同一应用提供静态资源，不增加生产Node进程。

该决定减少独立服务的运行与运维开销，也接受嵌入数据库的部署和扩展边界；存储格式、恢复与未来迁移存在实质成本。文件原文不长期保存，具体表结构、备份/迁移、数据库故障策略、资源隔离及native/AOT支持仍需设计和实测；这不是财务级账本或多副本数据库能力的承诺，也不表示实现已完成。
