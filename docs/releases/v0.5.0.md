# llmgw4j v0.5.0

发布日期：2026-11-20（Asia/Shanghai）。

v0.5.0 在 v0.4.0 的单进程 Java + SQLite 控制面之上，交付租户预付费计费与第 9 章治理收口，并把 MCP 网关、客户幂等键与审批工作流接入数据面。JDK 25、两套 JVM 数据面（WebFlux/VT）与原生命名 SPI 保持不变。

## 新增与修复

- 租户预付费计费（ADR-0007）：租户账户统一充值、余额、透支与项目子限额；客户售价独立于上游成本，按调用冻结售价版本；估算预留、权威用量结算、结果未知跨重启待对账；人民币 0.000001 元尾数按租户持久累计；精确/语义缓存命中零价；重试或回退仅按最终服务该调用的一次尝试计费；缺适用售价或计费规则拒绝调用。
- 严格预算模式（ADR-0009）与软预算默认并存：严格模式预留可证明的最大计费消耗（输入估算 + 显式输出上界），无上界的调用被拒绝；客户幂等键（同项目同键防重、内容不一致拒绝、不带键视为新调用）；审批工作流以挂起-重新准入约束转发（ADR-0011）。
- MCP 网关首版（ADR-0010）：Modern 下游与单向 Legacy 桥接、默认关闭、工具过滤与调用再鉴权；Gemini HTTP 双向接入，新增转换限于 OpenAI Chat（ADR-0008）。单机交付边界见 ADR-0006。
- 治理加固：认证主体财务归属强制（§9.5.2，billing.enabled 或 production 下 key 必须携带 `llmgw.tenantId`/`llmgw.projectId`）；策略版本戳、结构化判定与归属链审计、`gen_ai.*` 观测桥；Redis 故障策略 fail-closed 与治理不可用 503 + `Retry-After`；业务与审计同事务提交。
- 控制面与 OpenAPI 扩充：计费账户、价格版本、充值、待对账、幂等键、审批、录制与载荷存储端点；SQLite 迁移至 V13（计费 V10、幂等 V12、审批 V13；未装配对应实现包时按顺序跳过）。
- 引入 [spring-javaformat](https://github.com/spring-io/spring-javaformat) 0.0.48：模块内 539 个 Java 文件中的 444 个统一为 Spring 官方风格（Tab、120 列），`validate` 阶段强制。
- 修复：旧 `/admin` 创建 key 省略 `group` 时 500（`key_store.group_name` NOT NULL 违约，现归一化为 `""`）；心跳背压测试在全量负载下的时序 flaky（取消计数改为有界等待）；7 个回归脚本的 mock 端口/控制面 DB 隔离/计费种子/共享根密钥缺陷。
- Redis 双副本共享配额与跨副本故障恢复回归本轮收口（v0.4.0 后遗留的未收口项）。

## 升级步骤与兼容变化

1. 停止旧实例写流量，用 SQLite 一致性备份保存数据库并保留旧产物；`LLMGW_ROOT_KEY` 单独备份。不要复制仍在写入的主库。
2. 实例保持独占 `LLMGW_CONTROL_DB` 与 `llmgw.spool-directory`，数据目录同时容纳 WAL/SHM；首次启动自动迁移 V9 → V13，迁移按顺序执行，缺失计费/幂等/审批实现包时对应版本跳过。
3. 启用计费（`gateway.billing.enabled=true`）或 production 前：为静态 key 配置 `llmgw.tenantId`/`llmgw.projectId` 元数据；先为项目显式授权额度（新增 key 不会凭空铸额度）；为模型配置客户售价版本，否则请求被拒绝。
4. 预付费账户需先充值（管理面 `/control/accounts`、`/control/price`、`/control/quotas`）；待对账项必须核实后结算或释放，在途预留不可核销。
5. 预算模式默认 soft；需要可证明金额上界时显式启用 strict，并确保调用携带显式输出上界。幂等键通过 `Idempotency-Key` 传递（同项目内生效，非 `X-Request-Id`）。
6. Redis 可选治理新增故障策略：默认 fail-closed（治理不可用时 503 + `Retry-After`）；升级须统一副本版本，旧副本不识别新增键与 Lua 脚本。
7. 回退须知：不要让 v0.4.0 直接写已迁移到 V13 的库；回退需同时恢复旧产物与旧库备份。

## 资产与运行

Release 工作流从本 tag 构建默认 JVM JAR、Redis JAR、文档归档、Linux amd64 WebFlux native 及 `SHA256SUMS`。默认 JAR 支持 `--spring.profiles.active=webflux` 或 `vt`；native 必须按引擎与平台构建，VT native 与其他平台需自行编译。

```sh
java -jar llmgw-app-0.5.0.jar --spring.profiles.active=webflux
# Redis 变体仍需 gateway.redis.enabled=true 与 Redis 连接参数
sha256sum -c SHA256SUMS
```

以 Release 实际附件与校验和为准，不以本机构建产物替代。
