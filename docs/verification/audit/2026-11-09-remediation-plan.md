# 审查修复实施计划

目标：落实 review.md 中已确认的生产约束，首先消除可复现越权和凭据失效问题，后修预算与发布安全边界。
规格：同目录 `2026-11-09-review.md` 的七条验收标准与 19 项发现。
架构：保留 core SPI、两引擎与治理实现分层；共享层实现安全不变量，两引擎执行同一策略。不能可靠支持的生产能力明确拒绝，不能静默退化。
技术栈：Java 25、Maven、JUnit、现有 Redis/Caffeine；不增加框架。

执行：每组先加能重现缺陷的测试并验证失败，再实施修复，最后运行相关测试。独立文件组并行实施，集成后统一 verify 和双引擎契约验证。不提交或发布。

## 任务 1：凭据生命周期与持久化
- 文件：ManagedApiKeyRegistry、JsonKeyStore、相关 JUnit。
- 回归：轮换旧 token 吊销、过期旧 token 重启、重启 ID 唯一、并发持久化与写失败。
- 修复：稳定唯一 ID、历史凭据归属、原子持久化与错误传播。
- 验证：governance-default 定向测试，保留失败/成功证据。

## 任务 2：缓存及异步资源隔离
- 文件：TaskRouteSticky 与实现、两引擎资源控制器、向量缓存与相关 JUnit/HTTP 契约。
- 回归：跨 key/协议/模型缓存不命中，跨租户读删取消拒绝，未知归属拒绝。
- 修复：在查找之前按稳定身份和协议分区；绑定与查询覆盖相同维度；共享层统一语义。
- 与预算组共用 DefaultGovernanceChain 时，只修改 cache/lookupCache 段落，避免覆盖 enter/finish。

## 任务 3：构建部署与公开契约
- 文件：CI/release、Dockerfile/compose、OpenAPI、安全/部署文档。
- 修复：verify 测试门槛、双引擎契约、Redis 镜像与连接配置、native 产物路径、重复 YAML 键。
- 验证：严格 YAML 解析、脚本语法、可用时容器配置解析；标明未实际运行的远端发布。

## 任务 4：生产治理与费用边界
- 文件：GatewayProperties、生产启动校验、HttpGuardrail、ForwardingPolicy、BudgetLedger/QuotaMath、准入和结算路径、相关测试。
- 回归：生产危险配置失败，强制审核异常不放行，预算溢出/并发不可穿透，结果未知不自动重试。
- 对尚无可靠恢复账本/计费上界的生产硬预算明确拒绝启动或准入，避免声称财务保证。
- 外部治理隔离阻塞调用；二进制转发至少加明确响应大小/并发边界，避免无界内存。

- Maven verify、模块布局检查、双引擎关键契约与隔离探针。
- 检查有效旧凭据、空输入、未知资源、上游超时、磁盘失败等边界。
- 更新报告逐项状态与剩余限制，不将未验证项标为完成。
