## 使用与迁移注意

- 本地演示继续可用；共享生产环境必须启用 `gateway.production=true`（或 LLMGW_PRODUCTION=true）并替换示例 key、设置管理凭据。不要只设置生产标记而保留演示配置。
- 旧的未分区任务绑定无法证明归属，升级后不再授权访问；内存归属重启后丢失的资源也返回 404。需要跨副本/重启的资源归属使用 Redis 实现。
- 若旧 key store 已出现两个当前 token 共用同一身份 ID，应先备份并明确归属后迁移，不能自动合并账本或任选一个凭据恢复。
- JSON 密钥持久化原子性仅限单进程。Redis 包不提供运行时密钥创建/轮换/吊销，接口返回 501，不要共享 JSON 文件补成该能力。
- 财务级硬预算、大二进制流式下载及隔离列表均没有伪装为已完成能力。金额预算在生产被拒绝，未知结果保守保留预留，演示账本不提供自动对账恢复。
- native 编译、真实付费上游、远端 CI/Release/Central、长期压力与依赖 CVE 扫描未执行。历史性能数字不能替代修复后的性能测量；本轮没有做全面 SaaS 安全认证。
