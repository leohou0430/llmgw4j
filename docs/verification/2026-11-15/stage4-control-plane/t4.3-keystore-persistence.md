# T4.3/T4.4 KeyStore SQLite 持久化（hash-at-rest，运行时验证）

日期：2026-11-15
变更：app `ManagedKeyService` 由 `InMemoryKeyStore` 改为持久化 `SqliteKeyStore(controlDatabase, hashAtRest=true)`（与账号/路由版本同一 SQLite 库；V2 `key_store` 表）。

## 运行时实测（构建产物 + 重启）

| 步骤 | 结果 |
| --- | --- |
| 登录 + POST /control/keys | 200（一次性明文+掩码返回） |
| sqlite `count(*) from key_store` | **1** |
| `length(at_rest)`（存储键） | **64**（SHA-256 十六进制摘要，**非明文**） |
| kill -9 → 重启同库 | 200 |
| 重启后 `count(*) from key_store` | **1**（持久保留） |

- 结论：API key 以 hash-at-rest 形式持久化到 SQLite，跨进程重启保留；明文不在库中。
