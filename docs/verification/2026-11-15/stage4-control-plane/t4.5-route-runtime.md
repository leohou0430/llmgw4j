# T4.5 路由版本端点运行时实测（构建产物）

日期：2026-11-15
产物/运行：同 `t4.4-auth-runtime.md`（`llmgw-app-0.3.1.jar`，webflux，port 18085，env 首管理员）。
新增：`ControlRouteController` — `GET /control/routes`、`POST /control/routes/publish`、`POST /control/routes/rollback`，均经 `RequestAuthorizer`（会话+CSRF+RBAC ROUTE_PUBLISH/ROUTE_ROLLBACK）后调用 `RouteVersionService`。

## 实测结果（真实 HTTP，登录后携 cookie+CSRF）

| 步骤 | 结果 |
| --- | --- |
| POST /control/routes/publish expected=0 config=routes-A | 200 `{"version":1,"activeVersion":1}` |
| POST /control/routes/publish expected=1 config=routes-B | 200 `{"version":2,"activeVersion":2}` |
| POST /control/routes/rollback expected=2 target=1 | 200 `{"version":3,"baseVersion":1}`（新版本引用目标，不重写历史） |
| GET /control/routes | 200 `{"activeVersion":3}` |
| POST /control/routes/publish expected=0（过期期望） | **409**（乐观并发拒绝） |

- 证明：草稿→不可变发布→本进程激活、期望版本防并发（409）、回滚生成新版本在真实进程生效。
