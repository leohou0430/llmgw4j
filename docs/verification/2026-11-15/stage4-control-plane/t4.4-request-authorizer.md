# T4.4/T4.10 认证请求守卫（会话 + CSRF + RBAC 组合）

日期：2026-11-15
模块：`llmgw-identity-api`（AccountStore 增 `findById`）+ `llmgw-identity-default`（RequestAuthorizer / AuthOutcome / AuthenticatedRequest，`.local`）。

## 合同（管理端点认证中间件核心）

`RequestAuthorizer.authorize(AuthenticatedRequest)` 按序：
1. 会话有效（`SessionStore.find`）否则 `UNAUTHENTICATED`；
2. 会话所属账号存在且启用（`AccountStore.findById`）否则 `UNAUTHENTICATED`；
3. 变更请求（mutating）必须通过 CSRF（`CsrfTokenService.verify`，会话绑定）否则 `CSRF_FAILED`；只读不要求 CSRF；
4. 由账号 role+scope 构成 Subject，`AuthorizationService.decide(action,target)` 否则 `FORBIDDEN`。
全部服务端校验（非隐藏按钮）。
