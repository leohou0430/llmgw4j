# T4.7 供应商密钥 AES-GCM 存储（运行时）

- 迁移 V6：`upstream_secret(id, tenant_id, project_id, name, cipher_text, rotated_from, created_at, updated_at)`；schema_version=6。
- `SecretStore`（app）：只落 `cipher.encrypt(...)` 密文；读取时进程内解密后返回 `****`+后4位；根密钥来自环境 `LLMGW_ROOT_KEY`（base64 32B），缺失时 `StaticRootKey.missing()` → 503 fail-closed。
- 端点：`POST /control/secrets`、`GET /control/secrets`、`POST /control/secrets/{id}/rotate`；权限 SOURCE_MANAGE（平台级），写操作审计。页面未新增菜单（API 已可用）。
- 单测：`SecretStoreTest` 5/5（密文非明文、掩码、轮换、重开实例、无密钥 fail-closed）；`BackupRestoreTest` 迁移版本 6 通过。
