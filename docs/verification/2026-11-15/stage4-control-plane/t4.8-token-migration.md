- 默认 `DISABLED`：X-Admin-Token 永不进行远程管理。
- 显式 `MIGRATION`：仅 loopback 或受限管理网客户端接受，且判定为**可审计紧急平台权限**（`emergencyPlatform=true`），非普通登录会话、非无 scope 后门。
