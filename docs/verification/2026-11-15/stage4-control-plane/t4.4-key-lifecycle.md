# T4.4 管理 API（可测核心：key 生命周期 + RBAC 强制）

日期：2026-11-15
模块：`llmgw-identity-default`（ManagedKeyService，`.local`），复用 `RbacAuthorizationService`（T4.3）、`KeyStore`（core）、`CredentialIssuer`（T4.4 掩码）。

## 合同

- `ManagedKeyService.create(actor, target, key)`：服务端 `decide(KEY_MANAGE)` 合法才执行；issue 一次性明文；`KeyStore.upsert(plaintext, key)` 持久化；返回 `IssuedCredential(plaintext, masked)`。
- `readMasked(...)`：鉴权后仅返回掩码（`****`），绝不返回明文。
- `revoke(...)`：鉴权后 `KeyStore.delete(token)`。
- 越权/跨项目/只读角色 → `SecurityException`（服务端强制，不靠隐藏按钮）。
