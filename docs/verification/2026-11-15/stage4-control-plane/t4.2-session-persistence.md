# T4.2 会话 SQLite 持久化（跨重启会话存活，运行时验证）

日期：2026-11-16
变更：迁移 **V5** `session(id PK, account_id, expires_at_epoch_ms, token_version, created_at)`；app `SqliteSessionStore`（create/find 过期过滤/revoke/revokeAllForAccount，不关闭共享连接）；装配 `SessionStore` 改用 SQLite（与账号/key/路由同库）。

## 运行时实测（构建产物 + 重启）

| 步骤 | 结果 |
| --- | --- |
| 登录 | Set-Cookie（HttpOnly/SameSite）；sqlite `count(*) from session`=1 |
| GET /control/status（同 cookie） | 200 |
| kill -9 → 重启同一 DB | 200 |
| **重启后 GET /control/status（同一 cookie，未重登）** | **200**（会话从 SQLite 恢复） |
| 重启后 GET /control/audit（同一 cookie） | 200 |

- 结论：服务端随机会话持久化到 SQLite，进程重启后既有会话仍有效；过期仍由 `find` 时间过滤。
