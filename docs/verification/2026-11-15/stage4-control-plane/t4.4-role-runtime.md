# T4.4/T4.3 角色越权反例运行时验证

日期：2026-11-15
产物：`llmgw-app-0.3.1.jar`（`mvn -o -pl llmgw-app -am package -DskipTests` BUILD SUCCESS）。
运行：webflux，port 18087；env 提供平台管理员 `root` 与项目只读 `viewer1`（`LLMGW_VIEWER_USERNAME/PASSWORD`，scope t1/p1；无默认凭据，均显式 env）。

## 实测（真实 HTTP，登录后 cookie+CSRF）

| 角色 | 操作 | 结果 |
| --- | --- | --- |
| root（PLATFORM_ADMIN） | POST /control/keys (t1,p1,KEY_MANAGE) | **200** |
| viewer1（PROJECT_VIEWER, t1/p1） | POST /control/keys (t1,p1,KEY_MANAGE) | **403** |

- 证明：同一端点按调用者 role+scope 在服务端强制授权，只读角色越权写被拒（越权反例），管理员放行；会话+CSRF 前置同样生效。
