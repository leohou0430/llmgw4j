# T4.12 native AOT（vt，本机 macOS x86_64）

- 命令：`bash bin/build-native.sh vt`（`-Pnative -Dllmgw.native.profile=vt`）
- 首次构建：成功，`llmgw-app/target/llmgw-vt` 254,399,368 bytes；运行发现 **/control/secrets 返回 500**：
  `UnsupportedFeatureError: Record components not available for record class ...SecretStore$SecretSummary`
  ——Jackson 3 序列化 record 需要 native 反射注册。
- 修复：`GatewayRuntimeHints` 注册控制面请求体与响应 record（ResourceEntry、SecretSummary、EntryBody、CreateBody、LoginBody、TenantBody/ProjectBody、PublishBody/RollbackBody、SecretBody），重建。
