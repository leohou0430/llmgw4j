# T4.9 审计接线（写动作 + 读端点，运行时验证）

日期：2026-11-16
变更：app `AuditLog`（`audit_event` 表 insert/recent，不关闭共享连接）；`ControlKeyController.create` 与 `ControlRouteController.publish/rollback` 成功后写审计（action + 非敏感 detail）；新增 `ControlAuditController` `GET /control/audit`（`RequestAuthorizer` AUDIT_READ，无 CSRF）。

## 运行时实测（构建产物）

| 步骤 | 结果 |
| --- | --- |
| 登录 + POST /control/keys | 200 |
| POST /control/routes/publish | 200 |
| GET /control/audit（admin） | `{"events":[{"action":"route.publish","detail":"version=1"},{"action":"key.create","detail":"id=k1"}]}` |
| GET /control/audit（viewer, AUDIT_READ） | **200**（本项目可读） |
| sqlite `count(*) from audit_event` | 2 |

- 结论：管理动作产生脱敏审计事件并可经 RBAC 读取；只读观察者在项目内经 AUDIT_READ 可读其项目审计。
