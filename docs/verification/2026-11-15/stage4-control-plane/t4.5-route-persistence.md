# T4.5 路由版本 SQLite 持久化 + 启动恢复（运行时验证）

日期：2026-11-15
变更：迁移 **V3** 新增 `route_version(version PK, config, base_version, created_at)`；新增 app `SqliteRouteVersionStore`（实现 `RouteVersionStore`）；`ControlPlaneManagementConfiguration` 增加 `SqliteContext` bean（`LLMGW_CONTROL_DB`，默认 `./data/llmgw-control.db`，destroyMethod=close，启动跑 `Migrations.all()` V1–V3），`RouteVersionService` 改用 SQLite 存储。
修复：`SqliteRouteVersionStore` 初版用 try-with-resources 关闭了**共享连接**导致 `database connection closed`（发布 400）；改为不关闭 connection（由 context 拥有）。

## 运行时实测（构建产物 + 重启）

| 步骤 | 结果 |
| --- | --- |
| 启动（`LLMGW_CONTROL_DB=/tmp/cpd.db`）health | 200；schema_version=3 |
| 登录 + POST /control/routes/publish (expected=0, routes-A) | 200 `{"version":1,"activeVersion":1}` |
| GET /control/routes | `{"activeVersion":1}` |
| kill -9 进程 | — |
| **重启同一 DB** → health | 200 |
| GET /control/routes | **`{"activeVersion":1}`（从 SQLite 恢复）** |

- 结论：路由版本持久化到 SQLite，进程被强杀后重启可恢复已提交激活版本（启动恢复）。
