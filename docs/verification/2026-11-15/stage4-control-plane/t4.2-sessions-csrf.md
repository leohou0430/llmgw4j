# T4.2 登录与会话（纯基础部件）

日期：2026-11-15
模块：`llmgw-identity-api`（Session/SessionStore/CsrfTokenService/LoginRateLimiter）+ `llmgw-identity-default`（InMemorySessionStore/FixedWindowRateLimiter/HmacCsrfTokenService/SessionService，均在 `.local`）。

## 合同

- `Session(id, accountId, expiresAt, tokenVersion)`：id 为 256-bit 随机（非凭据派生）；过期不可见。
- `InMemorySessionStore`：create/find(过期过滤)/revoke/revokeAllForAccount。
- `HmacCsrfTokenService`：token = 随机 nonce + HMAC-SHA256(sessionId|nonce)，会话绑定，`MessageDigest.isEqual` 常数时间校验。
- `FixedWindowRateLimiter(max, windowMs)`：每 key 每窗口最多 max 次。
- `SessionService`：login（仅 enabled 且密码正确的账号建会话）；changePassword（重哈希并 `revokeAllForAccount` 失效活会话）。
