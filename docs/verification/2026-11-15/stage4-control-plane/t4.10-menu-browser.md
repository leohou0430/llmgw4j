# T4.4 租户/项目端点 + T4.10 多菜单浏览器实测

日期：2026-11-16
新增：app `OrgStore`（V1 tenant/project 表）、`ControlOrgController`（`GET/POST /control/tenants`、`GET/POST /control/projects`，CATALOG_READ 读、TENANT_MANAGE 写、写审计）；`index.html` 扩展为多菜单（登录/状态/租户/项目/key/路由/审计）。

## 运行时实测（构建产物）

### API（webflux）
| 操作 | 结果 |
| --- | --- |
| admin POST /control/tenants {t1} | 200 |
| admin POST /control/projects {p1,t1} | 200 |
| admin GET /control/tenants, /projects | 200（返回已建） |
| viewer POST /control/tenants | **403** |
| viewer GET /control/tenants | **200**（CATALOG_READ） |

### 浏览器（browser-use，页面注入驱动）
| 角色/操作 | 结果（DOM 返回） |
| --- | --- |
| admin 登录 → 建租户/项目/key → 发布 → 列表 → 审计 | 全 200；key 返回一次性明文+`sk-****…`；audit 含 `route.publish(version=1)`、`key.create(id=k1)` |
| viewer 登录 → 建租户 / 建 key | **403 / 403** |
| viewer 登录 → 读租户 / 读审计 | **200 / 200** |

- 结论：多菜单网页在真实浏览器可用；服务端按角色强制写/读权限（admin 全通，viewer 写拒读允）。
