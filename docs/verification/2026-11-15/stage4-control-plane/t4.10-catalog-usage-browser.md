# T4.10 新增菜单浏览器实测（Catalog / Usage）

运行实例：`llmgw-app-0.3.1.jar --spring.profiles.active=webflux`，env 驱动 root/viewer，独立控制库。

## 通过页面 UI 函数驱动（等价点击按钮）

MCP 原生 click 在本页两次 15s 超时（自动化侧问题，非页面报错；控制台无消息），改用页面内既有 `login()/createCatalog()/listCatalog()/usage()/audit()` 执行并读取对应 `<pre>` 输出。

| 场景（来源） | 操作 | 结果 |
|---|---|---|
| admin（127.0.0.1，库 cp-browser.db） | 登录 → 建目录 gw-ui-2 → 列出 → usage → audit | `logged in`；catalog 200 含 gw-ui-2；usage `200 {"usage":{}}`；audit 含 catalog.create |
| viewer（localhost，干净库 cp-browser3.db 首登） | 登录 → 建目录 gw-viewer-first | **403 Forbidden**（页面显示服务端错误体） |

## 观察（如实记录）

- 同一浏览器在同一来源连续切换不同账号且无登出/清 cookie 时，观察到请求归属不确定（旧会话 cookie 与新会话并存），曾出现 viewer 操作返回 200；以干净来源（localhost 新库）首登 viewer 复测为 403，curl 独立会话亦 403/读 200。服务端按实际会话鉴权正确；这是缺少 logout/会话吊销与浏览器 cookie 并存导致的自动化侧混淆。
- 后续待补：`POST /control/logout`（吊销会话并清 cookie）。当前未实现，列入仍缺。
