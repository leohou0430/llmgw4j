# T4.4 双引擎运行时验证（webflux + vt）

日期：2026-11-15
产物：`llmgw-app/target/llmgw-app-0.3.1.jar`（含控制面端点；`mvn -o -pl llmgw-app -am package -DskipTests` BUILD SUCCESS）。
运行：`java -jar ... --spring.profiles.active=vt --server.port=18086` + env 首管理员（GraalVM JDK 25），Tomcat/虚拟线程引擎。

## 实测结果（vt 引擎，真实 HTTP）

| 项 | 结果 |
| --- | --- |
| /actuator/health | 200 |
| GET /control/status | 200，真实 JSON（rbac/keyLifecycle/routeVersions/configValidation，credentialReadDenied=true） |
| POST /control/login | 200（cookie+CSRF） |
| POST /control/keys（cookie+CSRF） | 200 |
| POST /control/routes/publish（expected=0） | 200 `{"version":1,"activeVersion":1}` |
| GET /control/index.html | 200 |
| 关闭 | 优雅关闭（GracefulShutdown） |

- 结论：控制面（登录/CSRF/RBAC/key/路由版本/静态页）在 **vt 引擎**与 webflux 引擎下运行时均可用（双引擎 parity）。webflux 侧见 `t4.4-auth-runtime.md`、`t4.5-route-runtime.md`。
