## 合同

- `ConfigValidator.validate(candidate, policy) -> List<String>`（空=通过）。
- scheme 必须在 `PlatformPolicy.allowedSchemes`（平台权限；项目不能放宽）。
- host 为私网/回环/链路本地/元数据 IPv4 字面量（0/8、127/8、10/8、172.16/12、192.168/16、169.254/16 含 169.254.169.254）时，除非 `policy.allowPrivateNetwork()` 否则拒绝。
- timeout ∈ [50, 600000] ms；maxConcurrency ∈ [1, 10000]。
- 敏感头（authorization/cookie/set-cookie/proxy-authorization/x-admin-token/x-api-key）不得从客户端转发到上游。
- name 非空白。
