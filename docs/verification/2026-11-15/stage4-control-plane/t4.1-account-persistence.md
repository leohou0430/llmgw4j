# T4.1/T4.2 账号 SQLite 持久化 + 跨重启恢复（运行时验证）

日期：2026-11-15
变更：迁移 **V4** `account(id PK, username UNIQUE, password_hash, role, tenant_id, project_id, enabled, created_at)`；新增 app `SqliteAccountStore`（实现 `AccountStore`，不关闭共享连接）；`ControlPlaneManagementConfiguration.accountStore` 改用 SQLite（`LLMGW_CONTROL_DB`，与路由版本同库）。

## 运行时实测（构建产物 + 重启）

| 步骤 | 结果 |
| --- | --- |
| 冷启动（env 首管理员 bootstrap）health | 200 |
| POST /control/login (root) | **200** |
| sqlite `select count(*) from account` | **1** |
| kill -9 → 重启同一 DB → health | 200 |
| POST /control/login (root) 重启后 | **200**（账号从 SQLite 恢复） |
| sqlite count 重启后 | **1**（bootstrap 已跳过，无重复） |

- 结论：账号持久化到 SQLite；首管理员由 env 显式 bootstrap 一次后跨进程重启保留；登录依据持久账号成功。
