# T4.11 进程强杀与重启恢复（运行时）

JAR（webflux 18170，独立库 /tmp/cp-kill.db）：

1. 登录 → 建 key `k-kill` → 发布路由（activeVersion=1）。
2. `kill -9` 进程（未做优雅关闭，WAL 文件仍在）。
3. 同库重启 → 登录 → 检查。

| 检查 | 结果 |
|---|---|
| 强杀后 DB 中 key 行 | 1（WAL 数据已持久） |
| 重启后 GET /control/keys | 200，含 k-kill（掩码读取） |
| 重启后 GET /control/routes | activeVersion=1（启动恢复已提交版本） |
| schema_version | 6 |
