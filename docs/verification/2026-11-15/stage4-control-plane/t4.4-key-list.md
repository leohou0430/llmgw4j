# T4.4 key 读取（掩码列表）运行时验证

日期：2026-11-15
变更：`ManagedKeyService.list(actor,target)`（服务端筛选为 id/name/masked，绝不回明文）；`ControlKeyController` 新增 `GET /control/keys`（`RequestAuthorizer` 读权限 KEY_MANAGE，无 CSRF 需求）。

## 运行时实测（构建产物）

| 步骤 | 结果 |
| --- | --- |
| 登录(admin) + POST /control/keys(k1) | 200 |
| GET /control/keys（admin cookie） | `{"keys":[{"masked":"****","name":"demo","id":"k1"}]}` |
| 响应是否含 `sk-` 明文 | **0**（不泄露） |
| GET /control/keys（viewer cookie） | **403** |

- 结论：key 读取仅返回掩码/标识，不返回明文；只读角色越权读取被拒。
