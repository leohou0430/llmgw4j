# T4.1 账号与角色（llmgw-identity 域）

日期：2026-11-15
模块：新域 `llmgw-identity`（聚合 parent + 唯一 `llmgw-identity-api` + `llmgw-identity-default`），接入根 POM。

## 合同

- `Role`：PLATFORM_ADMIN / TENANT_ADMIN / PROJECT_ADMIN / PROJECT_VIEWER。
- `Scope(tenantId, projectId)`：platform()/tenant(id)/project(t,p)；空串=该层不限。
- `Account(id, username, passwordHash, role, scope, enabled)`：只存密码哈希，不存原文。
- `PasswordHasher`：hash/verify；`Pbkdf2PasswordHasher` 用 JDK `PBKDF2WithHmacSHA256`（成熟标准 KDF，非自实现密码学原语），每哈希新 16B 盐，编码 `pbkdf2$<iter>$<salt>$<digest>`，`MessageDigest.isEqual` 常数时间校验。
- `AccountStore` SPI + 内存实现（默认）；create 拒绝重复用户名；updatePassword；existsAny。
- `AdministratorBootstrap`：一次性本地 bootstrap 建唯一 PLATFORM_ADMIN，显式用户名+密码（无默认凭据/无公网注册），已有账号则拒绝。
