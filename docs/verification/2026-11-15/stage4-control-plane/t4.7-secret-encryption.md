# T4.7 密钥静态加密

日期：2026-11-15
模块：新域 `llmgw-control`（parent + `llmgw-control-api` + `llmgw-control-default`），接入根 POM。

## 合同

- `SecretCipher`：authenticated at-rest encryption（`encrypt`/`decrypt`）。
- `RootKeyProvider.requireRootKey()`：根密钥从库外安全注入（env/secret/KMS）；缺失抛 `RootKeyMissingException`（fail-closed）。
- `AesGcmSecretCipher`：AES-256-GCM（AEAD），每次加密随机 12B IV + 128-bit tag，输出 Base64(IV||ciphertext+tag)；篡改或错钥认证失败抛 IllegalStateException；每操作向 provider 取根密钥。
- `StaticRootKey`：显式注入的固定根密钥；`StaticRootKey.missing()` 为 fail-closed provider。
- 实现类在 `.local` 子包（布局合规）。
