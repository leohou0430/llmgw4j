# T4.4 认证管理端点运行时实测（构建产物）

日期：2026-11-15
产物：`llmgw-app/target/llmgw-app-0.3.1.jar`（`mvn -o -pl llmgw-app -am package -DskipTests` BUILD SUCCESS）。
运行：`LLMGW_ADMIN_USERNAME=root LLMGW_ADMIN_PASSWORD=*** java -jar ... --spring.profiles.active=webflux --server.port=18084`（GraalVM JDK 25），health=200。
新增：`ControlPlaneManagementConfiguration`（装配 AccountStore/PasswordHasher/SessionStore/CsrfTokenService/RbacAuthorizationService/ManagedKeyService/SessionService/RequestAuthorizer/RouteVersionService/ConfigValidator；env 驱动一次性首管理员 bootstrap，无默认凭据）、`ControlLoginController`（POST /control/login）、`ControlKeyController`（POST /control/keys）、`InMemoryKeyStore`。

## 实测结果（真实 HTTP，全链路）

| 步骤 | 结果 |
| --- | --- |
| POST /control/login (root 正确密码) | 200；`Set-Cookie: llmgw_sid=…; Path=/control; Max-Age=3600; HttpOnly; SameSite=Lax`；body `{"csrfToken":"…"}` |
| POST /control/login (错误密码) | 401 |
| POST /control/keys（cookie + X-CSRF-Token） | 200；`{"plaintext":"sk-…","masked":"sk-****ZbTg"}`（明文仅此一次，masked 只露首尾） |
| POST /control/keys（有 cookie、无 CSRF） | **403** |
| POST /control/keys（有 CSRF、无 cookie） | **401** |

- 证明：会话 + CSRF(变更) + RBAC(KEY_MANAGE) 服务端强制在真实进程生效；key 创建一次性明文、其余仅掩码。
- 结束后 kill，端口关闭；无残留。
- 修正：CSRF 失败由 401 改为语义正确的 403（仅未认证→401）。
