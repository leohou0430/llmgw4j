# T4.10 浏览器每角色实测（含越权反例）

日期：2026-11-15
产物：`llmgw-app-0.3.1.jar`（含功能网页壳 + 控制面端点 + admin/viewer env 账号），webflux，port 18088。
浏览器：browser-use（CDP attached）。in-app 视口为隐藏（viewport 0x0 → 指针点击/截图不可用），故在**真实浏览器页面上下文**中以注入脚本调用页面自身处理器（`login()`/`publish()`）驱动，并读取 DOM 文本——仍是浏览器内执行 + 真实服务端往返。

## 实测结果

| 步骤 | 结果 |
| --- | --- |
| navigate `/control/index.html` | 成功；快照元素：username/password/Login、Refresh status、routes JSON/expectedVersion/Publish |
| admin(root) 页面登录 → Refresh status | 状态 DOM 显示真实 JSON：`rbac=RbacAuthorizationService … credentialReadDenied=true` |
| admin 页面 Publish(routes-A, expected0) | 结果 DOM：`200 {"activeVersion":1,"version":1}` |
| viewer1(PROJECT_VIEWER) 页面登录 → Publish(routes-B, expected1) | 结果 DOM：**`403 Forbidden`**（`path=/control/routes/publish`） |

- 结论：网页壳在真实浏览器可用（登录+状态+发布），且**每角色动作差异**成立：平台管理员发布成功，只读观察者越权发布被服务端 403 拒绝（UI 触发、服务端强制）。

## 口径（未覆盖 / 诚实说明）

- 因 in-app 浏览器视口隐藏，使用页面注入脚本调用页面处理器代替物理鼠标点击；未对每个菜单逐一点击（当前菜单仅登录/状态/发布三项，尚未实现租户/项目/key/目录/用量/审计页面）。
- 未截图（视口隐藏）；以 DOM 读取 + 快照结构为证据。
- 内存存储；native/持久化未接线。
- 未提交/推送（用户惯例）。

## 复现

app 以 `LLMGW_ADMIN_USERNAME/PASSWORD` 与 `LLMGW_VIEWER_USERNAME/PASSWORD` 启动；browser-use 打开 `/control/index.html`，注入 `login()`/`publish()` 驱动并读取 `#status`/`#result`。
