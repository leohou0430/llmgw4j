# T4.5 路由版本（草稿→发布→激活；期望版本；回滚新版本；启动恢复）

日期：2026-11-15
模块：`llmgw-control-api`（RouteVersion/RouteVersionStore/VersionConflictException）+ `llmgw-control-default`（RouteVersionService/InMemoryRouteVersionStore，`.local`）。

## 合同

- 草稿（saveDraft，非空）→ 发布（publish(expectedVersion)）：不可变版本；本进程原子激活；`expectedVersion` 必须等于当前激活版本，否则 `VersionConflictException`（防并发覆盖）。
- 回滚 `rollback(targetVersion, expectedVersion)`：生成**新版本**引用目标版本 config（`baseVersion=targetVersion`），**不重写历史**；同样校验期望版本。
- 启动恢复：构造时 `store.latest()` 恢复当前激活版本/config。
- 单副本本进程激活；**不声称**跨副本发布确认。
- 版本存储 SPI（InMemory 默认；durable SQLite 后续）。
