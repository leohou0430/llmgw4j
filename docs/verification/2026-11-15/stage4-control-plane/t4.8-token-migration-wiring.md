# T4.8 旧 token 迁移接线（运维入口，2026-11-16）

在 T4.8 策略（`AdminTokenPolicy`）之上补齐运行接线：配置、双引擎过滤器、审计落库、旧控制台退役。

## 配置

| 键 | 默认 | 说明 |
| --- | --- | --- |
| `gateway.admin-token-mode`（`LLMGW_ADMIN_TOKEN_MODE`） | `disabled` | `disabled` / `migration`，其他值启动即失败 |
| `gateway.admin-restricted-networks`（`LLMGW_ADMIN_RESTRICTED_NETWORKS`） | 空 | 逗号分隔的受限管理网：IPv4 CIDR（如 `10.1.2.0/24`）或精确地址（IPv4/IPv6，含方括号、`%zone`、`::ffff:` 映射） |

`RestrictedNetworks` 在构造时校验每一条目；非法 CIDR/前缀越界/非法地址直接失败，不会静默放宽或收窄。IPv4 与 IPv6 统一归一化后比较（`InetAddress.ofLiteral`，不做 DNS 解析）。

## 行为

- 仅当**已配置** legacy token 且请求携带 `X-Admin-Token`/`X-Admin-Read-Token` 时过滤器介入；`/admin/console` 豁免（已改为 302 → `/control/index.html`，旧只读页资源删除）。无 token 配置（demo）行为不变。
- `disabled`：带 legacy 头的 `/admin/*` 一律 403，包括 loopback。
- `migration`：loopback（`127.*`、`::1`、`0:0:0:0:0:0:0:1`）或受限管理网 → 放行，并在放行前写 `audit_event(action=admin.legacy-token, project=platform, detail="METHOD path client=…")`；审计不可用则 503，不放行。公网 → 403。
- 不带 legacy 头的请求仍由 `AdminController` 自身判定（未配置时 demo 开放，配置时 401），与 JWT 校验正交。
