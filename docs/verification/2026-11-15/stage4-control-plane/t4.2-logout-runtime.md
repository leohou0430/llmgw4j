# T4.2 登出与会话吊销端点（运行时）

新增 `POST /control/logout`（会话 + CSRF 校验；吊销服务端会话并清空 cookie；页面新增 Logout 按钮）。

实测（JAR `llmgw-app-0.3.1.jar`，webflux 18140，独立库）：

| 检查 | 结果 |
|---|---|
| 登录后 GET /control/audit | 200 |
| POST /control/logout（带 CSRF） | 200 `{"loggedOut":true}` |
| 登出后 GET /control/audit | **401** |
| 登出后 GET /control/catalog | **401** |
| 无 CSRF 的 logout | 401 |
| 登出后 session 行数 | 0（已吊销） |

说明：`GET /control/status` 为公开能力描述，不校验会话，故登出后仍 200，不作为吊销探针；受保护端点 401 已覆盖。此端点解决同一浏览器切换账号时旧会话残留问题（见 `t4.10-catalog-usage-browser.md` 观察）。
