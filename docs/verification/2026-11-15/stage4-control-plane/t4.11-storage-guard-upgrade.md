# T4.11 磁盘保护接线与旧 schema 升级演练

## 写入拒绝（管理面全写路径）
- `WriteGate` 把 `StorageGuard.requireWritable()` 映射为 503；已接入：密钥创建、路由发布/回滚、目录创建、租户/项目创建、供应商密钥创建/轮换。

运行时（webflux，18230 `LLMGW_CONTROL_DB_MAX_BYTES=1` / 18231 默认 512MiB，独立库）：

| 写入端点 | cap=1 | 正常上限 |
|---|---|---|
| POST /control/keys | 503 | 200 |
| POST /control/routes/publish | 503 | 200 |
| POST /control/catalog | 503 | 200 |
| POST /control/tenants | 503 | 200 |
| POST /control/secrets | 503 | 200 |
| GET /control/catalog（读） | 200 | 200 |

cap=1 时 key_store 行数 0、activeVersion 0（无部分写入）；正常上限时 key_store 1、activeVersion 1。

## 旧 schema 升级
- 单测：`SchemaMigratorTest.upgradesAnExistingV1DatabaseToTheLatestVersionWithoutLosingData`（V1 → V6，tenant/resource_catalog 行保留，新表出现）。
- 端到端：用 sqlite3 构造 V1 库（schema_version=1 + 基础表 + tenant/resource_catalog 行），以该库启动 JAR：

| 检查 | 结果 |
|---|---|
| 启动后 schema_version | 6 |
| tenant 行 | legacy-tenant（保留） |
| resource_catalog 行 | 1（保留） |
| 新表 | key_store/route_version/account/session/upstream_secret 共 5 |
| 建密钥（守卫通过） | 200 |
