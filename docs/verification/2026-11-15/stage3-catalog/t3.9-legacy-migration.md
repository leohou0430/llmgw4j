# T3.9 旧资源迁移

日期：2026-11-15
模块：`llmgw-catalog-api`（LegacyResource/MigrationApproval/MigrationPreview/MigrationAuditSink）+ `llmgw-catalog-default`（LegacyMigrationService）。

## 合同

- 旧 key 空间独立保留：服务持有 legacySpace，迁移只读，不删除/改写旧资源；不扫供应商全账户导入。
- 显式审批映射才共享：`MigrationApproval(legacyOwner, tenantId, projectId, reviewerId, approved)`；仅 `approved=true` 且 legacyOwner 匹配才迁移；缺归属→rejected（**不猜**）。
- 冲突拒绝不合并：目标项目已存在同 gatewayId → conflicts，拒绝，不覆盖/不合并。
- 预览不落库：`preview` 只计算（audit "previewed"）；`apply` 才 `catalog.create`（audit "migrated"）。
- 每条决策审计：rejected-no-approval / conflict / migrated(/previewed)。
- 兼容入口限原 owner：`lookupLegacy(legacyOwner, legacyId)` 仅在 owner 匹配时返回。
