## 合同（与 JsonKeyStore parity，行为级）

| 方法 | 行为 |
| --- | --- |
| upsert(token,key) | 以 at-rest key（hash 模式=SHA-256 hex，否则明文）写入；完整 ApiKey（id/name/quotaTokens/allowedModels/expiresAt/group/budgetMicroUsd/metadata）；**重置** rotatedTo/legacyUntil（与 JsonKeyStore putKey 一致） |
| delete(token) / deleteAtRest | 删除 key_store + 子表 |
| rotate(old,new,overlap) / rotateAtRest | 旧条目记 rotatedTo=new 与 legacyUntil=overlap（不新建新条目，与 JsonKeyStore markRotated 一致） |
| load() | Map<atRest, StoredKey>；rotatedTo 空→null，legacyUntil<=0→0（与 JsonKeyStore 一致） |
| enabled() | true |

- 原文不进库：hash 模式下仅存 SHA-256 摘要（测试用固定 token 的独立 SHA-256 字面量断言，`sk-test-token`→`389faa3c...`）。
- allowedModels/metadata 用子表规范化存储（无 JSON 依赖，参数化，无注入面）。

## 替换/失败路径

- `installsByExplicitReplaceBeforeSealAndFailsAfterInstantiation`：`bind(KeyStore)` 占位后 `replace(KeyStore → SqliteKeyStore)`（seal 前）成功且 `get` 返回 SqliteKeyStore；已 `get` 实例化后再 `replace` 抛 `IllegalStateException`（未知/非法替换失败路径）。
