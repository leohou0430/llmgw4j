# T3.8 删除/取消状态机

日期：2026-11-15
模块：`llmgw-catalog-api`（DeletionState/DeletionRecord/RawContentUnavailableException/UpstreamDeleter/UpstreamDeleteChecker）+ `llmgw-catalog-default`（DeletionService）。

## 状态机

- `DeletionState`：PENDING →（上游确认）CONFIRMED /（失败/超时）UNKNOWN。
- `requestDelete`：查条目 → 记录 PENDING → `UpstreamDeleter.delete(sourceRoute, upstreamId)`（透传固定来源）；成功→CONFIRMED，异常→UNKNOWN。**不自动重试**（非幂等删除），attempts=1。
- `reconcile`：仅对已存在记录执行 `UpstreamDeleteChecker.deleted(...)`；确认→CONFIRMED，否则维持；attempts+1（人工触发核对）。
- 删除状态独立于目录条目：`catalog.delete` 移除条目**不会**产生 CONFIRMED 记录（删除目录≠上游已删除）。
- `downloadRaw` 一律抛 `RawContentUnavailableException`（无原文持久化/下载）。
