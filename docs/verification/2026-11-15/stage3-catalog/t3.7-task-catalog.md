# T3.7 任务目录（仅异步资源 + 取消透传）

日期：2026-11-15
模块：`llmgw-catalog-api`（TaskCatalog/TaskCanceller）+ `llmgw-catalog-default`（LocalTaskCatalog）。

## 实现要点

- 仅接受异步类型 batch/video；其它类型在访问前拒绝（IllegalArgumentException）。
- 目录/元数据/状态/分页委托底层 ResourceCatalog（共享序列与签名游标）。
- 取消：查条目 → `TaskCanceller.cancel(entry.sourceRoute(), entry.upstreamId())` **透传到条目固定来源** → 上游确认后才把状态标记 "cancelled"；上游拒绝则异常上抛、条目不标记。
- 不实现网关执行器/队列/恢复调度；不冒充真实供应商任务执行/验收（测试用 fake canceller 代替受控上游）。
