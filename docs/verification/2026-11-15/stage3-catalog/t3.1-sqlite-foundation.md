## 合同/接缝

- `llmgw-persistence-api`：`DatabaseContext extends AutoCloseable`，仅暴露 JDK `java.sql.Connection connection()`；只依赖 llmgw-core，无 SQLite/Spring/Reactor/连接池。
- `llmgw-persistence-sqlite`：`SqliteContext`（单连接，`jdbc:sqlite:<file>`，WAL + busy_timeout + foreign_keys=ON，close 幂等）；`SqliteConfig(Path, long)`；`SqliteModule implements ExtensionModule` 经描述符 `sqlite=<FQN>` 命名发现，`bindDefault(DatabaseContext)`。
- 资源归属：`ExtensionContext.get` 自动跟踪 AutoCloseable 并在 `close()` 逆序释放 —— `SqliteModuleTest` 断言 `ExtensionContext.close()` 关闭被持有的 SqliteContext（满足"修改资源必须覆盖关闭与实例隔离"）。实例隔离：不同文件互不可见（测试断言 B 查 A 的表抛 SQLException）。
- foundation 规则：`llmgw-persistence` parent `llmgw.foundation.enforcer.skip=false`；无 Spring/Reactor/HTTP 依赖；多实现模块规则（parent + 唯一 api + 每实现独立 child）。

## Native JNI

sqlite-jdbc 3.53.2.1 自带 `META-INF/native-image/org.xerial/sqlite-jdbc/native-image.properties`（`--enable-url-protocols=jar --features=org.sqlite.nativeimage.SqliteJdbcFeature`）并 bundled Mac/Linux 原生库；JNI/资源/反射由该 GraalVM Feature 在 native-image 构建时自动注册，**无需自定义 JNI 配置**。完整 native-image 构建属重型 native 门，另行执行（本任务不声称 native 已构建验证）。
