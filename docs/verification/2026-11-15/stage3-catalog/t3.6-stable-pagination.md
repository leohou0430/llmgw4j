# T3.6 稳定分页（签名游标 + 高水位 + 页大小）

日期：2026-11-15
模块：`llmgw-catalog-api`（PageRequest/CatalogPage/CatalogCursorException + ResourceCatalog.page 默认）+ `llmgw-catalog-default`（LocalResourceCatalog 重写为序列化存储 + 分页；CursorCodec HMAC）。

## 实现要点

- LocalResourceCatalog 每项目用 `TreeMap<时间序列, ResourceEntry>` 存储（AtomicLong 单调创建序），gatewayId→序列索引；create/get/delete/list 保持原行为并在项目状态上 `synchronized`。
- `page(tenantId, projectId, PageRequest, cursor)`：
  - 首屏：`highWaterMark = sequence.get()`（当前最大序），afterSequence=MIN；后续页从签名游标恢复 hwm + 上次最后序列。
  - 期间新建条目 seq > hwm → 不进入本次遍历。
  - 过滤 type；页大小限 `PageRequest.MAX_LIMIT=50`（构造期校验 1..50）。
  - `nextCursor` 仅为「还有更多匹配」时签发。
- CursorCodec：HMAC-SHA256 签名 + Base64URL；token 绑定 tenantId/projectId/typeFilter/highWaterMark/lastSequence；篡改签名拒绝；调用方校验 tenant/project/filter 一致（否则 `CatalogCursorException`）。
- 陈旧可读：条目携带 `lastSyncedAt`，分页原样返回，调用方可据以判定陈旧。
