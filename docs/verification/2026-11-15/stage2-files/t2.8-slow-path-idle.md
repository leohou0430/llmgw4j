## 2. 生产改动

`JdkHttpUpstream.java` fetchStream 的 Source：
- 新增 `volatile boolean idleTimedOut`。
- `next()` 每次阻塞读前按 `idleReadTimeoutMs` 调度 watchdog：到期 `readDone.compareAndSet(false,true)` 后置 `idleTimedOut=true` 并 `close()`（关闭响应 InputStream 解除阻塞读）；读返回后 `readDone.set(true)` + 取消 timer，消除"读已返回但 timer 恰好到期"的竞态。
- 读抛 IOException 且 idleTimedOut → 译为 `UpstreamTimeoutException("upstream idle read timeout")`；正常返回路径不变（累计 maxResponseBytes 上限、EOF、close 幂等保留）。
- 更新 javadoc：T2.8 per-read idle 已硬化；整请求超时仍约束交换起始。
