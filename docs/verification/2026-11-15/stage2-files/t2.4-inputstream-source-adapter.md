# T2.4 前置切片：core InputStream → ByteStream.Source 有界适配器

日期：2026-11-15 ｜ 阶段：2（Files 有界流式）｜ 任务：#96（隶属 #95 两引擎 Files 流式桥）

## 目标与接缝

为 VT/WebFlux 上传桥提供把客户端 `InputStream` 喂给 `MultipartUpload.prepare` 的前置原语。
上传方向需要一个**可复用、无累计上限**的 pull `Source`：有界分块、EOF 返回 null、
`close()` 幂等且仅释放底层流一次、读错误透传。字节上限由下游 `MultipartScanner`
（file/multipart/metadata）与 `Spool`（transfer/total/disk）强制，故本传输适配器
刻意不带累计 cap（与下载方向 `JdkHttpUpstream.fetchStream` 的 maxResponseBytes 内联
适配器区分：那是 provider 私有、带响应上限；本切片是 core 公共、上传方向、无 cap）。

被测接缝（pre-agreed，core 纯 JDK）：`ByteStream.inputStreamSource(InputStream, int)`
公共工厂 + 返回 `Source` 的 `next()/close()` 行为。
