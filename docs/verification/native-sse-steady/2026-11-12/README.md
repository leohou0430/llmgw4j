## 固定条件

2 CPU / 2 GiB、禁swap、最大堆1GiB、单副本；WebFlux SSE、64并发，两种运行时各预热60秒，交错三轮各60秒的负载窗口。每个trial前后要求宿主1分钟负载/逻辑核心数≤0.75。这里60秒是采样窗口，不是每条SSE持续60秒。使用本地受控上游，不追加供应商调用。

| 运行时 | 三轮p99 ms | p99中位数 ms | 成功请求/秒中位数 | 容器CPU ms/成功请求 | 进程累计cgroup峰值 MiB |
|---|---|---:|---:|---:|---:|
| JVM | 122.5, 122.5, 119.9 | 122.5 | 580.1 | 1.459 | 381.8 |
| native Serial | 144.0, 141.2, 137.5 | 141.2 | 564.8 | 1.817 | 256.3 |

本批native/JVM p99比值1.153、吞吐比值0.974；最初1.58倍及短批次2.57倍差异没有在此稳态批次复现，但native仍有约15%的尾延迟差距。单纯缩小年轻代的旧试验没有收益，不采用。接下来单独验证项目已有G1 native构建，不把它的未完成结果混入本表。

p99是三轮各自p99的中位数，不是合并分位数；峰值内存跨每个进程生命周期累计，CPU/成功请求包含采样/排空时段。负载门槛是粗筛，不能证明没有调度、频率或其他短时干扰，不能推广为生产SLO或供应商最大QPS。
